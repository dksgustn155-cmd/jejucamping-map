# 📢 지자체 고시(告示) 수동 수집 방법 — 데모 지역

> 조례가 "규칙의 틀"이라면, **고시는 "이 구역/주소를 금지구역으로 지정"** 하는 실제 문서.
> 국가 API에 거의 없어 **수동 수집**. 저장처: `data/raw/notices.jsonl` (양식 아래).

## 3단계 방법

### 1) 어디서 찾나 (데모 지역)
| 지역 | 고시·공고 게시판 |
|---|---|
| **담양군** | 담양군청 홈페이지 → 정보공개/새소식 → **고시·공고** 게시판 |
| **제주도** | https://www.jeju.go.kr/news/news/law/jeju2.htm (입법·고시·공고) |
| **전국(통합)** | **토지이음** https://www.eum.go.kr → 고시정보 (지역·키워드 검색) ⭐ 여러 지자체 고시 모임 |
| **국가하천** | 유역환경청·시도 하천관리본부 (예: 낙동강관리본부 "낚시·취사·야영 금지구역 지정 고시") |

### 2) 뭘 검색하나 (키워드)
`야영 금지` · `취사 금지` · `금지구역 지정` · `출입통제` · `하천 낚시` · `차박` · 해수욕장/오름/공원명

### 3) 어떻게 저장하나 → `data/raw/notices.jsonl` (한 줄 = 고시 1건)
```json
{"id":"notice:담양-영산강-2025", "지자체":"전라남도 담양군",
 "고시명":"영산강 하천구역 낚시·야영·취사 금지구역 지정", "종류":"고시",
 "날짜":"2025", "대상장소":"담양읍 학동리 학동교~삼다리 백진공원 8.5km 구간",
 "금지행위":"낚시·야영·취사", "요약":"하천 둔치 캠핑카·카라반 증가로 쓰레기·수질오염 → 금지구역 지정",
 "출처":"담양군 고시(홈페이지 확인)", "상태":"행정예고→확인필요"}
```
> `대상장소`에 **구체 주소·구간**을 넣는 게 핵심(RAG가 지점과 대조). `상태`로 예고/확정 구분.

## ⚠️ 주의
- 뉴스 기사는 참고용, **최종 확정 고시는 지자체 홈페이지 원문으로 확인**하고 고시번호·일자 기입
- "행정예고"는 아직 확정 전일 수 있음 → 시행일 확인
- 저작권: 고시는 공공저작물(자유이용). 출처(지자체·고시번호) 명기
