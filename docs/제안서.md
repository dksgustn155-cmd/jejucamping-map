## 0. 개요

### 아이템 소개
**"떠나고 싶은 곳"만 입력하면, 그 주변의 검증된 공공 편의시설·안전정보·관련 규정을 지도와 대화로 한눈에 보여줘, 사용자가 자기에게 맞는 캠핑·차박 장소를 스스로 쉽게 발견하도록 돕는 웹 서비스.**

- **목적**: 비싸고 시간 제약이 많은 캠핑장 대신 자유로운 차박·자연 휴식을 원하는 사람이, **믿을 수 있는 정보로 안심하고 좋은 장소를 직접 찾도록** 공공데이터로 돕는다. (우리가 대신 골라주는 것이 아니라, **발견을 쉽게** 만든다.)
- **핵심 기능**
  1. **대화형 발견** — *"이번 주말 담양으로 아이들이랑 계곡 근처, 화장실 가까운 데 있을까?"* 처럼 물으면, 조건(지역·기간·동반·선호)을 이해해 **그 지역의 검증된 시설·안전·규정 정보를 근거와 함께** 정리해 보여주고, 각 지점의 적합도(화장실 근접·뷰·침수안전 등)를 **표시**해 사용자의 판단을 돕는다.
  2. **지도 발견** — 전국 공공데이터 **11종 86,723건**을 지도 레이어로 제공하고, **로드뷰·실시간 CCTV 영상·전기차 실시간 가용**으로 사용자가 **직접 눈으로 확인·검증**하며 발견한다.

### 아이템의 특징 및 차별성
- **"안내"가 아니라 "검증 가능한 발견"**: 기존 차박·노지 정보 서비스(**캠카, 오지캠핑** 등)는 **커뮤니티·블로그 기반이라 정보가 한정적이고, 실제로 가보기 전엔 검증하기 어려운 장소를 그냥 위치만 안내**한다(폐쇄·시설 없음·불법 여부 불명). 우리는 **정부 공공데이터(실존하는 화장실·주차장·CCTV, 좌표·개방시간·법령)**로 뒷받침하고, **로드뷰로 직접 확인**까지 붙여 *"믿고 발견"*하게 한다.
- **공공데이터 86,723건 + RAG + 실시간 정보의 결합**: 실제 좌표·개방시간·법령·실시간 상태에 **근거한** 정보 제공.
- **기본 GPT와의 차이**: ChatGPT는 "전국 6만 개 화장실 좌표", "지금 이 충전소 급속 몇 대 남았는지", "이 지점 취사가 합법인지"를 **모른다**. 우리는 이를 출처 데이터로 답한다.
- **합법성 프레이밍**: "불법 노지 조장"이 아니라 "선택 지점 주변 공공시설 안내 + 합법 야영장 병행 제시".

## 1. 문제인식

### 프로젝트 목표 및 목적
> **① 캠핑장은 비싸고 시간 제약이 크고, ② 그 대안인 차박·노지는 정보가 부실하고 검증이 어렵다.**

- **①** 성수기 오토캠핑장 1박 5~10만 원, 글램핑 15만 원 이상. 그런데 입실(14~15시)·퇴실(11시)이 엄격해 실제 체류는 **20시간 미만** → 쉬러 갔다 이동·설치·철수로 **더 피곤**해지는 역설.
- **②** 그래서 차박 수요가 급증했지만, 이용자는 *"어디가 안전하고, 화장실·주차·물이 있고, 법적으로 문제없는지"* 를 알기 어렵다.
  - 기존 서비스(**캠카·오지캠핑** 등)는 **블로그·커뮤니티에서 모은 장소를 위치만 안내** → 정보가 **부정확·오래됨**, 막상 가보면 폐쇄됐거나 화장실·주차가 없거나 취사 금지 구역인 경우가 잦다. **검증할 방법이 없다.**

**목표**: 차박·자연 휴식을 원하는 사람에게, **검증 가능한 공공데이터**로 안전·편의·합법성을 스스로 확인하며 **좋은 장소를 쉽게 발견**하도록 돕는다.

### 아이템의 독창성 (유사 서비스 대조)
| 구분 | 기존 서비스 | 한계 | 우리 서비스 |
|---|---|---|---|
| **차박/노지 정보앱 (캠카·오지캠핑 등)** | 커뮤니티·블로그 장소를 위치만 안내 | **정보 한정·검증 불가**, 실제와 다름, 편의·안전·합법성 정보 없음 | **공공데이터로 검증 가능**, 편의·안전·법령 함께, 로드뷰로 직접 확인 |
| 캠핑 예약앱(캠핑고 등) | 유료 캠핑장 예약 | 무료 차박·공공시설 미대상 | 무료 공공 편의시설 + 적합도 표시 |
| 지도앱(네이버·카카오) | 단순 장소 검색 | 차박 관점 정보 조합 없음 | 주차↔화장실↔뷰↔안전을 발견 관점으로 묶음 |
| 일반 챗봇(ChatGPT) | 일반 지식, 환각 | 실좌표·실시간·법령 모름 | 실데이터 근거 RAG |

→ "**검증 가능한 공공데이터 + RAG 비정형지식 + 실시간 정보**"로 *발견*을 돕는 서비스는 확인되지 않음.

## 2. 개발 및 연구 내용

### 구현 내용 상세

**시스템 구조 — "대화형 발견 도우미"**
```
사용자 질문 / 지도 탐색
  │
  ▼  ① 조건 파싱 (gpt-5-mini function calling)  → {지역, 기간, 동반, 선호(계곡/바다/EV)}
  ▼  ② 후보·주변시설 수집 (SQLite)              → 지역 내 주차장·야영장 + 근처 화장실·안전시설
  ▼  ③ 적합도 신호 계산 (근접 연산)             → 각 지점에 화장실150m·바다뷰·침수안전 등 '뱃지'
  ▼  ④ 근거 검색 (RAG: 임베딩→FAISS)            → 규정·소개문·축제 등 관련 문서 Top-k
  ▼  ⑤ 발견 응답 생성 (gpt-5-mini)              → 검증된 정보·근거를 정리해 제시 + 지도에 표시
  │        (판단은 사용자 몫 — 로드뷰·CCTV로 직접 확인)
  └─(로그)→ 주간 배치: 적합도 가중치·지식베이스 자동 갱신
```
> 핵심은 **"AI가 1곳을 골라주는 추천"이 아니라, 검증된 정보와 적합도 신호를 풍부하게 제시해 사용자가 스스로 발견**하게 하는 것. gpt-5-mini는 흩어진 데이터·근거를 **사람이 읽기 쉽게 정리**하는 역할.

**요구 데이터 (전국 공공데이터 11종 86,723건, 전부 좌표 확보)**
| 데이터 | 건수 | 출처(표준데이터) |
|---|---|---|
| 공중화장실 | 59,768 | 행안부 공중화장실 표준 |
| 공영주차장 | 17,007 | 전국주차장정보표준 `tn_pubr_prkplce_info_api` |
| 전기차 충전소 | 3,229 | 제주 ITS센터(+실시간 가용) |
| 야영장 | 3,023 | 한국관광공사 고캠핑(입지: 산/숲/계곡/해변) |
| 문화축제 | 1,043 | 전국문화축제표준(개최기간→혼잡 신호) |
| 클린하우스·관광안내소·해수욕장·둔치주차장(침수위험등급)·안전CCTV·심야약국 | 2,653 | 제주도/행안부 표준 |
> RAG 지식베이스 원문(비정형): 캠핑 규정·법령, 야영장 소개문, 축제·시티투어·테마파크·한옥체험 등 `data/raw/*.jsonl`

**모델 설계·활용 (평가: 모델 설계·활용)** — gpt-5-mini를 RAG와 어떻게 결합했는가
- **왜 RAG인가**: 공공시설 좌표·개방시간·법령은 gpt-5-mini의 학습지식에 없거나 부정확 → **검색으로 사실을 주입**하고 생성은 "정리·설명"만 맡겨 환각을 억제. (= "검증 가능한 발견"의 기술적 근간)
- **임베딩·검색**: 한국어 `sentence-transformers`로 문서를 벡터화 → `FAISS`로 질문과 유사한 문서 Top-k 검색.
- **정형 + 비정형 하이브리드**: 위치·시설은 SQLite 정형검색(정확), 규정·소개는 RAG 비정형검색(맥락) → 두 근거를 함께 프롬프트에 주입.
- **성능 향상 시도(복수)**:
  1. **환각 방지 프롬프트** — "전달된 근거·데이터만 인용, 없으면 '정보 없음'". 근거에 없는 장소·수치 생성 금지.
  2. **적합도 신호 계산** — 단순 검색이 아니라 화장실 근접·뷰·침수안전·혼잡을 정량화해 **뱃지·정렬**로 발견을 도움.
  3. **질문 학습 루프** — 클릭·👍 로그를 주간 배치로 분석해 적합도 **가중치**와 **지식베이스**를 갱신(모델 재학습이 아닌 검색·랭킹 개선).
  4. **조건 파싱(function calling)** — 자유문장을 구조화해 잘못된 검색을 줄임.
  5. **프레이밍 규칙** — 공영주차장에 "차박하세요" ❌ → "주차+화장실 가까운 지점" 우회.

**서비스 견고성 (평가: 서비스 견고성)**
- **안정성**: 정적 데이터는 SQLite로 빠르게 서빙, 실시간(전기차·날씨·CCTV)은 **짧은 TTL 캐시**로 API 폭주 방지. 외부 API 장애는 502로 격리해 지도는 계속 동작.
- **사용자 친화성**: 구글 홈처럼 검색창 중심 랜딩, 예시 질문 칩, 지도 레이어 토글, 로드뷰로 현장 확인. 좌표 없는 결과·로드뷰 미제공 지점 등 엣지케이스 안내.
- **데이터 신선도**: `refresh_all.py` 월 1회 배치로 갱신, 축제는 주 1회 → 기존 서비스의 "오래된 정보" 문제를 구조적으로 방지.

### 개발 아이템 기대효과
- **이용자**: 검증 안 된 블로그 정보에 의존하지 않고, 안전·합법성을 **스스로 확인**하며 좋은 장소를 발견. 초행지도 화장실·주차·충전 걱정 해소.
- **지자체·관광**: 특정 명소 쏠림 대신 주변 공공시설로 **분산 유도**, 축제 혼잡 회피 안내로 지역 균형.
- **확장성**: 현재 제주 심화 + 전국 기본. 반려동물·장애인 편의·재난안전(하천 침수) 등 레이어 추가 용이. PWA로 모바일 설치형 전환 가능.

- **동일 질문셋**(담양·서귀포·전기차·법령 등 20문항)으로 평가.
- **정량 지표**
  - **사실 정확도**: 제시된 시설·좌표가 실제 공공데이터와 일치하는 비율 (단독 모델은 환각·"모름").
  - **좌표 오차(m)**: 제시 지점과 실제 좌표 거리.
  - **실존·최신율**: 안내된 장소가 실제 존재하고 운영 중인 비율 (기존 서비스는 폐쇄·변경 반영 안 됨).
  - **근거 인용률**: 답변이 출처(법령 조문·데이터)를 명시한 비율.
- **정성 지표**: 실제 법령 인용 여부, 실시간 정보(EV 가용·CCTV) 제공 여부, 합법성 프레이밍 준수.
- **대조 방식**: 원본·출처 데이터(공공 API 원본, 국가법령정보)와 각 답변을 직접 대조해 표로 제시 → *"검증 가능"* 을 정량으로 증명.

### 🛡️ 보안 (평가: 보안)
- **API 키**: 소스코드에 절대 하드코딩하지 않고 `.env`로 분리. **GitHub Actions CI가 커밋마다 키 하드코딩을 자동 검사**. 저장소는 **비공개**로 운영하고, 배포 시 키는 Cloud Run **환경변수**로만 주입. 카카오 JS 키는 **도메인 제한**으로 보호. **프로젝트 종료 후 전 키 재발급** 정책.
- **사용자 입력**: 화면 출력 시 **HTML 이스케이프(XSS 방지)**, 사용자 입력을 외부 URL·폼으로 전송하지 않음.
- **개인정보**: 대화 로그는 **익명 세션 ID**로만 저장(PII 미수집), 개인 위치는 서버에 영구 저장하지 않음.
