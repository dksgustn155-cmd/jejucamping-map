## 3. 핵심 의존성 — C와 먼저 합의 (A-3a)

채팅 답변 JSON에 **지도를 어떻게 움직일지**를 담을 규격을 C와 확정해야 함. 제안:

```json
{
  "reply": "…추천 텍스트…",
  "map": {
    "bbox": [33.24, 126.55, 33.27, 126.58],
    "layers": ["parking_public", "restroom"],
    "pins": [
      { "id": "…", "lat": 33.25, "lon": 126.56, "label": "추천 1위", "rank": 1 }
    ]
  }
}
```

이 규격이 있으면 A는 C의 API 완성 전에도 **mock 응답으로 UI를 먼저 완성**하고,
나중에 `fetch` 대상만 교체하면 됨.

👍👎 피드백 로그 UI → C의 로그 엔드포인트(#13)로 POST (엔드포인트·페이로드도 A-3a에서 함께 합의).
