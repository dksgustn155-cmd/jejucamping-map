# 🎤 발표 개요 — 숲으로 바다로 (20분 · 발표자 2인)

> 컨셉: **"비싸고 갑갑한 캠핑장 대신, 공공데이터로 안심하고 찾는 나만의 쉼터 — 제주에서 시작합니다"**
> 발표자: **D(개요·시연·회고)** + **테크 담당 1인(B 또는 C)**. 시간 19분 구성 + 1분 버퍼.

## 시간 배분 & 역할

| 파트 | 발표자 | 시간 | 평가영역 대응 |
|---|---|---|---|
| ① 문제 인식 | **D** | 4분 | 문제 정의·기획 |
| ② 우리 플랫폼 (데이터→사용) | **D** | 3분 | 문제 정의·기획 / 신뢰성 |
| ③ 라이브 데모 (제주) | **D** | 5분 | 서비스 견고성 / 신뢰성 |
| ④ 기술 (아키텍처·RAG·GCP·보안) | **테크** | 5분 | 모델 설계·활용 / 견고성 / 보안 |
| ⑤ 회고·한계·확장 | **D** | 2분 | 신뢰성(정직한 한계) |

## ① 문제 인식 (D, 4분 · 슬라이드 4장)

**S1. 타이틀** — 🌲숲으로 바다로🌊 (랜딩 화면 스크린샷 배경)
- 한 줄: "도시를 떠나 자연을 만끽하고 싶은 여러분, 떠나고 싶은 곳을 입력해 보세요"

**S2. 캠핑장의 현실 — 비싸고, 갑갑하다** ⭐제주부터
- **제주 등록 야영장 45곳**(우리 DB·고캠핑) — 글램핑·카라반 1박 **10~20만원대**
- 전국: 1회 캠핑 평균 지출 **14.1만(2023)→15.8만 원(2024)** ([한국관광공사 실태조사](https://datalab.visitkorea.or.kr))
- 입실 14~15시·퇴실 11시 → **실체류 20시간 내외**. 텐트 설치·철수에 반나절 → "쉬러 가서 더 피곤"

**S3. 그래서 캠핑족이 떠난다 (기사 인용)**
- 캠핑 인구 **634만(2023) → 546만(2024), 1년새 ▲88만** (관광공사)
- 기사 헤드라인 그대로: *"캠핑 한 번에 40만원? 차라리 호텔 간다"* ([머니투데이 2026.2](https://www.mt.co.kr/society/2026/02/15/2026021415320041363)), *"8조원 시장 반토막… 캠핑장 줄폐업"* ([땅집고](https://v.daum.net/v/bM3ZyvjJIh))
- → 트렌드는 **노지캠핑·차박**으로 이동 (담양 영산강 둔치 캠핑카 급증 → 군이 금지구역 지정할 정도)

**S4. 그런데 노지는 막막하다 — 기존 서비스의 한계**
- 어디가 **합법**인지(법령·조례), **화장실·주차·물**은 있는지, 침수 위험은 없는지 알 길이 없음
- 기존 앱(캠카·오지캠핑 등)은 **커뮤니티 제보 기반** → 폐쇄됐거나, 시설이 없거나, 불법인 곳을 그냥 안내 (📸 **스크린샷 삽입**: 기존 앱 장소 정보 화면 — 검증 정보 없음 강조)
- 한 줄 정리: *"장소는 알려주는데, **믿을 수가 없다**"*

## ② 우리 플랫폼 — 공공데이터로 "검증된 발견" (D, 3분 · 3장)

**S5. 해답: 공공 정보로 안심 쉼터 찾기**
- 정부 공공데이터 **11종 86,723건** + 법령·조례·고시 **330건** + 자연공원 경계 **154구역**
- "추천을 믿어라"가 아니라 **사용자가 직접 확인**: 로드뷰·실시간 CCTV·법령 원문 인용

**S6. 제주 특화 데이터 맵** ⭐ (제주 지도 그래픽 위에 숫자 얹기)
- 화장실 **849** · 공영주차장 **1,572** · EV충전소 **3,226(실시간 가용)** · 안전 CCTV **81(실시간 영상)** · 해수욕장 11 · 축제 43 · 심야약국 · 야영장 45
- "시스템은 전국 커버, **제주는 실시간·안전까지 심화**"

**S7. 어떻게 쓰나 (사용자 여정)**
- ①검색창에 자연어로 ("애월로 차박, 전기차야") → ②조건 이해 → ③지도에 검증된 시설+적합 신호 → ④로드뷰·CCTV로 눈 확인 → ⑤규정까지 인용
- 데이터 흐름 한 줄: 공공 API 수집→좌표 정규화→DB→실시간 API 결합 (상세는 기술 파트로)

## ③ 라이브 데모 — 제주 시나리오 (D, 5분) ⭐발표 하이라이트

> ⚠️ 반드시 **백업 녹화/스크린샷** 준비. 대본 고정, 즉흥 입력 금지.

1. **랜딩** — "이번 주말 제주 애월 차박, 전기차인데 화장실 가까운 조용한 곳" 입력 → 지도 전환+애월 이동+레이어 표시
2. **지도 탐색** — 공영주차장(🚗)+화장실(🚻) 조합 확인 → 마커 상세 카드
3. **킬러 1: EV 실시간** — 충전소 클릭 → "지금 급속 N대 충전 가능" (라이브 데이터 강조)
4. **킬러 2: 안전 CCTV** — 탑동 CCTV 클릭 → **실시간 파도 영상 재생** ("가기 전에 현장을 본다")
5. **킬러 3: 규정 판정** — 백록담 근처 지점 → *"한라산 국립공원 구역 — 자연공원법 제27조 야영·취사 금지(과태료 50만/20만)"* 자동 인용
6. **챗 마무리** — "한라산 근처에서 취사해도 돼?" → 법령 근거 답변 + 합법 야영장 45곳 대안 제시 (프레이밍 강조)

## ④ 기술 파트 (테크 담당, 5분 · 4장)

**S8. 아키텍처** — 파싱→정형검색(SQLite)→적합도 신호→RAG 검색(FAISS)→gpt-5-mini 생성 (다이어그램)
**S9. RAG 설계 — 왜·어떻게** (평가: 모델 설계·활용)
- gpt-5-mini는 좌표·법령을 모른다 → **검색으로 사실 주입, 생성은 정리만** (환각 억제)
- 성능 향상 시도 5종: 환각방지 프롬프트 / 적합도 신호 랭킹 / 질문 학습 루프(가중치·지식베이스 갱신) / function calling 조건 파싱 / 프레이밍 규칙
- **근거 3층**: 법령 원문(공식 API) → 지역 조례(238) → 좌표 판정(GIS 154구역)
**S10. 신뢰성 검증** — base gpt-5-mini vs 우리: 동일 20문항, 사실정확도·실존율·근거인용률 비교표 (7/9 측정 결과 삽입)
**S11. 견고성·보안·인프라**
- 견고성: 정적=SQLite, 실시간=TTL 캐시, 외부 API 장애 격리
- **GCP**: Cloud Run 서빙(서버리스·무트래픽 0원) + Cloud Build 자동 빌드 (+Scheduler 월간 데이터 갱신)
- 보안: 키 하드코딩 금지+CI 자동검사, 비공개 레포, XSS 이스케이프, 로그 익명(PII 미수집), 종료 후 키 재발급
- **앱 확장**: PWA로 홈화면 설치형(코드 그대로, HTTPS 충족) → Capacitor로 스토어 배포까지 가능

## ⑤ 회고·한계·확장 (D, 2분 · 2장)

**S12. 정직한 한계**
- 지번 단위 금지구역 "고시"는 지자체 게시판에 분산 → 전수 자동화 불가 (데모 지역만 수동 확보) → 답변은 "단정" 대신 "확인 권장" 프레이밍
- GIS 판정은 현재 자연공원 154구역 — 하천구역·해수욕장 폴리곤은 확장 예정(브이월드 WFS 레이어 확인 완료)
- 개방시간 자유텍스트 정규화, 데이터 신선도(월 배치) 의존

**S13. 회고 & 확장**
- 회고: 데이터 검증(원문 대조로 과태료 오류 3건 발견·수정), 좌표계 4종 통일, 팀 폴더 분리 협업
- 확장: 전국 서비스 확대 / 앱(PWA→스토어) / 반려동물·장애인 편의 레이어 / 지자체 협업(공식 고시 연동)
- 클로징: *"공공데이터는 이미 다 있었습니다. 우리는 그걸 **믿고 쓸 수 있게** 연결했을 뿐입니다."*
