# 🚀 실행 계획 (2026-07-03 확정 · 마감/발표 7/10(금) · 두 모드 다 개발)

## 서비스 = 두 모드, 지도는 카카오맵 JS로 통일

- **모드 1 — 대화형 추천**: "7/9 서귀포 가는데 허용 야영장 있어? 아니면 화장실+주차장 가까운 곳? 바다 보이면 좋겠어"
  → 데이터 검색 + GPT mini가 야영장 추천 / (공영주차장은 차박 금지라) **우회적으로** "이 근처 주차장+화장실 조합 방문 추천" / 해수욕장이면 만조·날씨 기반 **방문 타이밍** 안내
- **모드 2 — 지도 탐색**: 카카오맵 확대/축소로 화장실·주차장·야영장 마커 확인 + **로드뷰**로 현장 직접 살펴보고 사용자가 판단

## 확정 아키텍처 (BigQuery GIS 편입)

```
[데이터 파이프라인]
공공 API ──수집──▶ GCS (원본 JSONL) ──적재──▶ BigQuery (GEOGRAPHY 컬럼)
                                              │
                            ┌─────────────────┼──────────────────┐
                            ▼(GIS 전처리)                        ▼(export)
              BigQuery GIS: 시설간 근접도/추천 연산          serving SQLite
                            │                                    │
[서빙]                      ▼                                    ▼
프론트(HTML/JS+카카오맵) ──REST──▶ FastAPI (Cloud Run)
   ├ 탭1 채팅 추천 ───────────────▶ /api/chat        GPT mini + BigQuery GIS 질의
   └ 탭2 지도+마커+로드뷰 ─────────▶ /api/facilities  SQLite bbox 조회 (빠름)
                                   └ /api/beach-timing 기상청 해수욕장 날씨(실시간)

역할 분담: 모드1 추천=BigQuery GIS(스마트,1~2초OK) / 모드2 지도=SQLite(빠른 pan/zoom)
GCP 스택: GCS + BigQuery/GIS + Cloud Run + Cloud Build + Artifact Registry (+Scheduler 여유시)
```

## 발표 방어 논리
- **"왜 제주?"** → 시스템은 전국 동작(화장실 6만·야영장·해수욕장). 제주는 도정 오픈데이터가 제일 풍부해서 심화 기능(화장실 좌표 정밀·주차면수·월파CCTV 안전)을 얹기 좋음. "시스템 전국 준비 완료, 데이터 심화는 제주로 시연"
- "노지 캠핑 조장?" → 장소 추천 아님. 공공 편의시설 정보 + 등록 야영장(합법 대안) 제시. 공영주차장은 차박 권유 안 함(우회 안내만)
- "ChatGPT로 되잖아?" → 전국 6만 화장실 좌표·개방시간, 실시간 만조/파고, 제주 월파CCTV는 GPT에 없음
- "왜 GCP?" → 데이터(GCS) + BigQuery GIS(추천연산) + 서빙(Cloud Run) + 자동배포(Cloud Build) + (여유 시)Scheduler/GitHub Actions
