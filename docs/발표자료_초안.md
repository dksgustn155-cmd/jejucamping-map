# 기술: 어떻게 "믿을 수 있게" 만들었나

- 흐름: 질문 파싱 → 정형 검색(SQLite 8.6만 건) → 적합도 신호 → RAG 근거 검색 → gpt-5-mini 답변 생성
- **gpt-5-mini는 좌표·법령을 모릅니다** → 검색으로 사실을 주입하고, 생성은 "정리"만 (환각 억제)
- 근거 3층: ① 법령 원문(공식 API) ② 지역 조례 238건 ③ GIS 좌표 판정 154구역

# RAG × gpt-5-mini — 성능을 끌어올린 5가지 시도

1. **환각 방지 프롬프트** — 전달된 근거·수치만 인용, 없으면 "정보 없음"
2. **적합도 신호 랭킹** — 화장실 근접 · 뷰 · 침수 안전 · 혼잡(축제 기간)을 정량화
3. **질문 학습 루프** — 클릭·👍 로그로 가중치·지식베이스 주간 자동 갱신
4. **Function calling 조건 파싱** — 자유 문장을 구조화해 오검색 감소
5. **지역 인지 검색** — 사용자 지역의 조례를 우선 검색, 없으면 국가법 폴백

# 견고성 · 보안 · 인프라

- **안정성**: 정적 데이터는 SQLite, 실시간은 짧은 캐시(TTL) — 외부 API 장애에도 지도는 동작
- **GCP**: Cloud Run 서버리스 배포(트래픽 없으면 0원) + Cloud Build 자동 빌드 + Scheduler 월간 데이터 갱신
- **보안**: 키 하드코딩 금지(CI 자동 검사) · 비공개 저장소 · XSS 이스케이프 · 대화 로그 익명(개인정보 미수집) · 종료 후 전 키 재발급
- **앱**: PWA **적용 완료** — 폰 홈 화면에 설치되는 앱으로 이미 동작 (현장에서 설치 시연 가능) → 스토어 배포(Capacitor)까지 로드맵

# 정직한 한계

- 지번 단위 "금지구역 고시"는 각 지자체 게시판에 분산 — 전수 자동화 불가 (데모 지역은 수동 확보)
